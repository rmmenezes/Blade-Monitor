Saiba o que sua empresa expõe na internet antes de um atacante saber.

Blade Monitor é um monitor de exposição externa (EASM) open source. Ele descobre subdomínios, varre serviços, avalia riscos e avisa quando algo novo aparece na sua superfície de ataque.

Começar Ver relatório de exemplo

Como funciona

Cada execução gera um snapshot; o monitor compara com o anterior e só alerta sobre mudanças.

1 · DESCOBERTA

Ativos

Subdomínios via Certificate Transparency (crt.sh), resolução DNS, IPs e faixas CIDR.

2 · VARREDURA

Serviços

Portas TCP abertas, certificados TLS, respostas HTTP e banners de serviço.

3 · RISCO

Achados

Regras classificam cada problema de informativo a crítico.

4 · ALERTA

Mudanças

Diff entre execuções, relatórios Markdown/JSON e webhook para Slack, Teams ou Mattermost.

Plataforma multi-tenant

Além do CLI, o Blade Monitor inclui uma plataforma web (API REST + painel) para gerir a superfície de ataque de várias organizações.

Nota A–F

Nota de 0 a 100 por categoria (rede, TLS, web, vazamento de informação), com tendência histórica e relatório executivo.

Ciclo de vida dos achados

Achados abrem, resolvem e reabrem sozinhos entre varreduras; risco aceito e falso positivo exigem justificativa.

Posse verificada

Varredura ativa só após verificação por DNS TXT ou arquivo HTTP; IPs exigem atestado registrado em auditoria.

Risco de terceiros

Fornecedores avaliados de forma passiva (CT logs, DNS e uma visita HTTP/HTTPS), sem varredura de portas.

Programa de parceiros para consultorias

Consultorias e MSSPs gerenciam todos os clientes num portfólio único, com a própria marca.

Instalar e executar

Python 3.11 ou superior, sem dependências externas.

git clone https://github.com/rmmenezes/Blade-Monitor.git
cd Blade-Monitor
cp config.example.toml config.toml        # defina seus domínios e IPs
python -m blade_monitor scan              # uma varredura
python -m blade_monitor scan --interval 360   # contínuo, a cada 6 horas
python -m blade_monitor history           # snapshots anteriores

# Plataforma web (API + painel + fila de varreduras)
python -m blade_monitor.platform demo     # dados sintéticos para conhecer o painel
python -m blade_monitor.platform serve    # http://127.0.0.1:8080

Monitore apenas domínios e IPs que você possui ou tem autorização formal para testar.
